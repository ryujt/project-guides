## 쇼핑몰 서비스뷰 검증

2026-11-22(KST), `af945c5`에 추가한 [MSA 서비스뷰](../../examples/diagram/job-flow/system.md)를 [매크로 예제](../../examples/diagram/job-flow/macro.md)와 대조했다. `node guides/tools/design-doc-check.mjs --strict examples/diagram`으로 예제 폴더의 링크·앵커·펜스를 확인했다. 서비스뷰는 같은 검사에 `--renderer guides/tools/diagram/jobflow.mjs`와 임시 출력 경로를 지정해 실제 SVG로 변환했다.

서비스 간 직접 요청·회신과 독립 구독을 확인했고, SVG 원문 및 화살표 수가 각 블록·설명과 일치했다. 독립 검토에서 출고 중지 후 취소 거절, 늦게 도착한 완료 통지, 부분 취소와 주문 보상의 이중 환불 경로를 찾아 문서에 반영했다. 검증 범위는 가상의 서비스 계약과 도표이며 실제 결제·배송 연동은 포함하지 않는다.

## 구현 코드 잡플로우 검증

2026-11-22(KST), [구현 예제](../../examples/diagram/job-flow/implementation.md)의 JavaScript 블록 3개를 Node.js에서 각각 실행했다. 재생기의 프레임 순서와 빈 큐에서의 화면 유지, 중복 주문의 재고·품절 결과, 상품 필드 이름의 조회와 대체 값을 확인했다. 재고 예제의 시작점은 [서비스뷰 검증](#쇼핑몰-서비스뷰-검증)에서 확인한 재고 예약 요청에 맞췄다.

`node guides/tools/design-doc-check.mjs --strict examples/diagram`으로 예제 링크와 앵커를 검사했다. 구현 도표 4개는 같은 도구의 `--renderer guides/tools/diagram/jobflow.mjs` 옵션으로 SVG를 생성해 코드와 대조했다. 재고 예약에서는 기존 결과 조회 도형이 반환값 연결을 가리는 문제를 찾아 분기 선언 순서를 바꾸고 렌더링을 다시 확인했다.

## 비회원 주문 조회 분기 검증

2026-11-22(KST), [S02 서비스뷰](../../examples/diagram/job-flow/system.md#s02-비회원이-주문-한-건을-열람할-권한-얻기)의 문자 신청과 코드 제출을 독립 진입점으로 렌더링했다. 연락처 미확인 시 발급 종료, 접수 오류·응답 유실·접수 후 미전달의 차이, 코드 검증 후 열람·재입력·재발급을 [M02 매크로뷰](../../examples/diagram/job-flow/macro.md#m02-비회원이-인증-문자를-받아-주문-한-건-조회하기)와 대조했다. 같은 검증 요청을 재확인하는 경우와 사용한 코드를 새 요청에 제출하는 경우도 구분했다.

문자 접수 상태와 배달 결과는 공식 API 계약으로 확인했다. 서비스 간 회신과 코드 만료 처리는 예제의 설계이며 검증은 문서 검사와 도표 렌더링까지 수행했다. [SENS 발송 API](https://api.ncloud-docs.com/docs/sens-sms-send) · [SENS 응답 상태 코드](https://api.ncloud-docs.com/docs/sens-overview) · [SENS 발송 결과 조회](https://api.ncloud-docs.com/docs/sens-sms-get)

## 서비스뷰 분기와 스킬의 예제 선택

2026-11-22(KST), [서비스뷰](../../examples/diagram/job-flow/system.md)의 시나리오 전체를 [처리 결과 분기](../../guides/method-R.md#25-처리-결과의-분기로-메시지를-보내는-이유를-드러낸다) 기준으로 검토했다. 판매 조건과 재고 예약, 승인·환불 확인, 운송장과 배송 경과, 취소·반품·교환 및 리뷰 자격을 대조했다. 서비스 간 메시지·독립 구독의 소유자와 결과 조건, 화살표 175개와 굵은 표제의 순서를 대조하고 13개 도표의 SVG에서 분기 도형의 표시 이름까지 확인했다.

Claude·Codex·Gemini의 기본·SmartMD 임시 설치에서 예제 폴더로 연결되는 스킬 진입점 90개를 확인했다. 설치·문서 검사기 회귀 53건이 통과했다. 별도의 생성 실험에서는 도서관 방문 안내와 창구 대출을 한 도표에 작성했고, 임시 설치의 새 하위 폴더에 등록한 보관 자료 예제를 색인에 추가하지 않아도 유사한 조건의 절을 찾아 참고했다. 두 산출물의 잡플로우는 엄격 모드 검사와 SVG 렌더링을 통과했다.

변경된 가이드 9종의 진단을 기준 커밋과 비교했다. 기존 앵커 오류 9건과 표기 경고 9건이 남았고, 새 진단은 없었다.
