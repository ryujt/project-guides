# 설계 예제

## 시나리오 기반 상태 전이 분석서

[일반 쇼핑몰 분석서](diagram/state/shopping-mall-scenario-state-analysis.md)는 고객이 상품을 찾고 주문한 뒤 배송·환불·교환 결과를 확인하기까지의 상황을 다룬다. 각 상태도 아래에서 주요 상태와 전이 조건을 읽고, 이어지는 테스트 케이스에서 준비 조건과 행동 순서, 고객과 운영자가 확인할 결과를 찾을 수 있다. 정책을 정해야 하는 사례에는 설계 검토 항목을 표시한다.

## 다이어그램 예제 고르기

다이어그램을 작성하거나 수정할 때는 이 폴더의 현재 하위 폴더와 목차부터 살펴본다. [다이어그램 예제 목록](diagram/)에서 참고할 문제를 찾을 수 있다. 목차에 맞는 항목이 없으면 하위 폴더의 파일 목록과 문서 제목·소제목도 검색한다. 새로 추가된 자료도 같은 기준으로 고른다.

요청한 그림의 종류와 관찰 범위를 먼저 맞춘다. 그 안에서 다음 행동을 결정하는 조건이 비슷한 절을 읽는다. 서비스 간 협력이라면 누가 메시지를 받고 어떤 결과에서 다음 요청을 보내는지, 화면 이동이라면 어디서 진입하고 어떤 조건으로 복귀하는지, 상태도나 배치도라면 어떤 사건으로 상태가 바뀌거나 어떤 영역이 다른 영역을 포함하는지를 비교한다.

선택한 절에서 도형과 설명을 대응시키는 방식, 분기나 경계를 표현하는 방식을 참고한다. 실제 주체·계약·상태·동작은 대상의 구현 근거나 설계 요구에서 정한다. 맞는 사례가 없으면 해당 다이어그램의 전용 가이드와 대상 자료로 작성한다.
