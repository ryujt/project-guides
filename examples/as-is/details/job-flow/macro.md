# 고객 구매 흐름의 매크로 AS-IS

고객 UI·도메인·DB·내부 스케줄러·모듈을 모두 `쇼핑몰` 경계 안에 둔다. 고객·운영자·택배기사·결제사·택배사·인증 제공자·메일서버는 외부 역할이다. `택배사`는 운송장·배송 상태를 관리하는 택배사 업무 시스템 경계로 표현한다. 운영자가 사용하는 관리 UI도 `쇼핑몰` 경계 안에 둔다. 메시지는 업무 계약 이름이며 실제 endpoint·필드는 [화면 이동](../../navigation.md)과 구현 링크를 따른다. 제공자의 실제 화면·통신은 실행하지 않았다.

## 전체 시나리오

아래 매크로뷰는 주문·결제부터 운영자의 배송 의뢰·상품 인계, 택배사의 배달, 쇼핑몰의 배송 기록과 고객 알림, 메일을 통한 복구까지 보여 준다. 계정 이용은 아래 상세 절에서 다룬다. 각 `고객.On…`·`운영자.On…`·`택배기사.On…`·`택배사.On…`과 `결제사.On결제통지`는 업무 사건을 나타낸다. 상품 인계와 인수, 배달과 수령을 잇는 선은 실물 전달에 따른 사건의 관계이며 데이터 전송이 아니다. 배송 업무는 생성된 주문의 배송 대상 품목을 기준으로 이어지며, 위아래 배치가 모든 업무의 자동 실행이나 고정 순서를 뜻하지는 않는다. 운영자와 택배사 사이의 배송 의뢰·실물 인계·운송장 수령, 택배기사의 상품 배달·모바일 완료 등록은 코드 밖 업무의 대표 모델로 보완했다. 실제 현장 절차와 택배사별 계약은 확인하지 않았다.

| 시나리오 | 시작 행동 | 주요 결과·분기 | 상세 |
| --- | --- | --- | --- |
| 회원가입과 로그인 | 일반·외부 로그인 | 로그인 복귀·오류, 신규 외부 고객의 등록정책별 결과 | [회원가입과 로그인](#회원가입과-로그인) |
| 주문과 외부 결제 | 주문 제출 | 입력 보완, 직접 주문 처리 또는 외부 결제 확인·복귀 | [주문과 외부 결제](#주문과-외부-결제) |
| 배송 의뢰·인계·배달과 택배사 추적 | 운영자의 배송 준비·의뢰·인계, 택배기사의 배달·모바일 완료 등록, 고객의 배송 상세·추적 조회 | 상품 수령, 택배사의 배송 완료 기록, 쇼핑몰의 자동 완료 반영과 조건부 고객 메일, 택배사 추적 화면 | [배송과 택배사 추적](#배송과-택배사-추적) |
| 메일을 통한 확인·복구 | 복구 메일 신청·복구 링크 열기 | 복구 신청 안내, 대상이 있으면 메일 발송, 링크로 재설정 화면 진입 | [메일을 통한 확인·복구](#메일을-통한-확인복구) |

- 로그인은 모든 구매의 공통 선행 조건이 아니다. 게스트 구매 허용 여부와 로그인 후 복귀는 [N27](../../navigation.md#n27)을 따른다.
- 외부 인증 응답·브라우저 결제 복귀·결제사 통지는 서로 다른 입력이다. 제공자 통지 이후의 처리·고객 알림은 결제 모듈별 계약을 따른다.
- 주문 생성은 결제·배송 완료를 보장하지 않으며, 복구 신청 안내는 메일 배달 성공을 보장하지 않는다.
- 쇼핑몰은 운영자에게 배송 대상과 배송지를 제공하고, 운영자는 택배사에 배송을 의뢰한 뒤 운송장을 쇼핑몰에 입력한다. 택배기사는 상품을 배달하고 모바일로 택배사 시스템에 배송 완료를 등록한다. 이 외부 구간은 대표 업무 모델이며 택배기사 모바일 앱의 실제 계약은 확인하지 않았다.
- 택배기사의 완료 등록이 성공하면 `택배사.On배송완료등록`이 발생하고 쇼핑몰로 배송 완료를 자동 통지한다. 쇼핑몰은 통지를 받은 배송 단위의 완료 상태를 반영하고, 고객 알림 조건을 충족하면 완료 메일을 보낸다. 이 자동 연동은 요청에 따라 추가한 변경안이며 현재 구현으로 확인된 AS-IS 경로는 아니다.
- 고객의 택배사 추적은 배송 상세에 운송장 번호와 추적 URL이 있을 때 여는 외부 화면이다. 쇼핑몰의 배송 완료 기록과 택배사 화면의 현재 상태는 구분한다.
- 일반 회원가입과 등록정책별 안내는 [N05](../../navigation.md#n05), 이메일 계정 활성화는 [N06](../../navigation.md#n06), 뉴스레터 활성화는 [N48](../../navigation.md#n48)에서 확인한다. 전체 그림의 계정 관련 메일 경로는 아래 상세 절과 같이 비밀번호 복구를 대표로 표시한다.

## 회원가입과 로그인

```jobflow
scope: 고객 계정과 복귀
Object: 고객, 쇼핑몰, 인증제공자
고객.On일반로그인 --> 쇼핑몰.message.로그인신청
쇼핑몰.message.로그인신청 --> 쇼핑몰.계정판정
쇼핑몰.계정판정.로그인허용 --> 고객.message.로그인복귀
쇼핑몰.계정판정.로그인불가 --> 고객.message.로그인오류
고객.On외부로그인 --> 쇼핑몰.message.외부로그인신청
쇼핑몰.message.외부로그인신청 --> 인증제공자.message.인증요청
인증제공자.message.인증요청 --> 쇼핑몰.message.인증응답
쇼핑몰.message.인증응답 --> 쇼핑몰.외부계정판정
쇼핑몰.외부계정판정.기존계정허용 --> 고객.message.로그인복귀
쇼핑몰.외부계정판정.신규등록처리 --> 고객.message.등록정책별결과
쇼핑몰.외부계정판정.인증불가 --> 고객.message.로그인오류
```

- 일반 로그인 성공 시 게스트 장바구니를 회원 계정으로 이관한다.
- return URL은 로컬 URL인지 확인한다. checkout에서 로그인할 때의 복귀 대상은 장바구니다.
- 신규 외부 고객은 가입 중지·표준·메일 확인·관리자 승인 정책을 따른다.
- 외부 제공자의 내부 판단·SDK 수행 순서는 열지 않는다.

근거: [N03–N09](../../navigation.md#n03), `IdentityController`.

## 주문과 외부 결제

```jobflow
scope: 주문 제출과 제공자 확인
Object: 고객, 쇼핑몰, 결제사
고객.On주문제출 --> 쇼핑몰.message.주문신청
쇼핑몰.message.주문신청 --> 쇼핑몰.구매조건판정
쇼핑몰.구매조건판정.입력보완필요 --> 고객.message.주문입력안내
쇼핑몰.구매조건판정.외부확인필요 --> 결제사.message.결제확인요청
쇼핑몰.구매조건판정.직접주문처리가능 --> 고객.message.주문처리결과
결제사.message.결제확인요청 --> 쇼핑몰.message.결제복귀
쇼핑몰.message.결제복귀 --> 쇼핑몰.결제복귀판정
쇼핑몰.결제복귀판정.주문기록확인 --> 고객.message.주문처리결과
쇼핑몰.결제복귀판정.결제선택보완 --> 고객.message.결제선택안내
결제사.On결제통지 --> 쇼핑몰.message.결제제공자통지
```

- 주소·배송·결제·동의 검사는 적용 단계와 설정에 따라 수행한다.
- 브라우저 복귀와 provider webhook은 서로 다른 입력이다. 통지가 먼저 주문 복구를 끝냈으면 복귀 시 기존 주문을 확인할 수 있다.
- 통지 후 동작·고객 알림은 provider별 계약이다. 위 통지 수신 노드는 그 존재를 나타내며 모든 모듈에 같은 처리 순서·보장을 가정하지 않는다.
- 일반 주문 처리 결과에는 결제 대기 상태도 가능하다. 생성 완료를 결제·배송 완료로 해석하지 않는다.
- 외부 timeout·취소·중복 통지의 실제 결과와 재처리는 provider 계정·로그가 없어 미확인이다.

근거: [N27–N34](../../navigation.md#n27), `CheckoutWorkflow`, `OrderProcessingService`, 선택 결제 모듈.

## 검증 범위

쇼핑몰의 기존 화면·서비스와 업무 경계·판정·응답을 코드로 정적 대조했다. 택배사 완료 등록 후 쇼핑몰로 자동 통지해 완료를 반영하는 경로는 요청된 연동 변경안으로, 이 문서 수정에서 구현하거나 검증하지 않았다. 택배사 배송 의뢰·운송장 수령·실물 인계·택배기사의 배달·모바일 완료 등록은 관계를 설명하기 위한 대표 업무 모델이며, 현장 절차를 검증한 AS-IS 사실로 주장하지 않는다. Job Flow 파서·렌더러로 배치·겹침을 확인하지 않았다. 외부 요청을 실행하거나 결제·배송 의뢰·메일을 발생시키지 않았다. 택배사 추적 화면과 실물 배송 결과는 확인하지 않았다. 본문의 수신 메시지 이름은 설명용 계약 이름이며 실제 DTO·endpoint와 동일하다고 주장하지 않는다.
