# 큰 AS-IS 문서 예제 안내

여러 과업을 한 파일에 모으고 Navigation·Layout·페이지 HTML을 연결한 문서 구성을 참고하는 자료다. [Navigation](navigation.md)에서 시나리오 색인·페이지 대응과 필요한 시나리오 절만 읽고, 그 절에 등장하는 [화면 배치](screen-layout.md)와 HTML로 이동한다. 전체 본문을 기본 읽기 범위로 삼지 않는다.

Navigation 작성의 우선 기준은 [작성 샘플](../diagram/navigation/document-template.md)과 [Navigation 가이드](../../guides/navigation-diagram-guide.md#문서-구성과-화면-확인-링크)다. 이 큰 예제의 화면·API·코드 심볼·정책·분량은 대상 프로젝트의 요구사항이 아니다. 실제 프로젝트 문서를 이름만 바꾸어 새 예제로 옮기지 않는다.

이 예제에서 참조하는 원본 코드가 함께 제공되지 않은 링크는 현재 예제 위치에서 열리지 않을 수 있다. 과거의 확인 범위·실행 결과도 현재 작업의 검증으로 재사용하지 않는다. 화면 확인 링크의 완전성과 이동·장면의 의미는 새 작성 대상과 대조하며, 매 시나리오의 링크 구성은 [작은 완성 예제](../diagram/navigation/document-sample/navigation.md)를 따른다.
