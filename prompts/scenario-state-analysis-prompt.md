# 시나리오 기반 상태 전이 분석서 생성 프롬프트

사용자가 지정한 업무·시스템의 **시나리오 기반 상태 전이 분석서** 한 파일을 작성한다. 현재 동작을 묻는 요청은 AS-IS, 목표 동작을 설계하는 요청은 TO-BE 관점으로 작성한다. 업무 사례를 모델링하는 요청은 주어진 상황과 가정을 기준으로 삼는다.

[공통 작성 가이드](../guides/scenario-state-analysis-guide.md)에 따라 시나리오를 선정하고 각 절에 상태도와 분기·연쇄 변화의 근거를 담은 뒤 검증한다. 기존 설계서·상태 정의가 있으면 필요한 절을 상대 링크로 참조한다.

사용자가 지정한 위치에 저장한다. 같은 범위·관점의 분석서를 갱신할 때는 기존 파일을 사용한다. 새로 작성하고 지정 위치가 없으면 `docs/design/{DATE}/scenario-state-analysis.md`에 저장한다. `{DATE}`는 생성 일시의 `YYYYMMDD-HHMMSS` 형식이다. 결과에 파일 위치와 미확인·미결정 사항을 요약한다.

Markdown 문서·다이어그램의 tools.camp 링크 생성 여부 확인과 전달은 [편집 링크 전달 기준](../guides/diagram-editor-link-guide.md)을 따른다.
